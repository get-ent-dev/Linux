## Questions

**1.** Who created the Linux kernel, and in what year?

a) Richard Stallman, 1983  
b) Linus Torvalds, 1991  
c) Dennis Ritchie, 1969  
d) Ken Thompson, 1994  

---

**2.** What does the acronym "GNU" stand for?

a) General Network Utility  
b) GNU's Not Unix  
c) Global Network Ubuntu  
d) General Networking Utility  

---

**3.** Which of the following is NOT a Linux distribution?

a) Ubuntu  
b) AlmaLinux  
c) FreeBSD  
d) Fedora  

---

**4.** Which package manager does Ubuntu use?

a) `yum`  
b) `dnf`  
c) `apt`  
d) `pacman`  

---

**5.** What command installs WSL with the default Ubuntu distribution on Windows?

a) `wsl --setup`  
b) `wsl --install`  
c) `wsl --add ubuntu`  
d) `install-wsl`  

---

**6.** AlmaLinux is a free, binary-compatible rebuild of which enterprise Linux?

a) Debian  
b) SLES (SUSE Linux Enterprise)  
c) Ubuntu  
d) RHEL (Red Hat Enterprise Linux)  

---

**7.** Which of the following is a key advantage of Linux for production servers?

a) It has better gaming support than Windows  
b) It requires no command-line knowledge  
c) It has no per-seat licensing cost and is highly stable  
d) It comes pre-installed on most servers  

---

**8.** What is the minimum RAM recommended for a Ubuntu Server VM in this course?

a) 512 MB  
b) 1024 MB  
c) 2048 MB  
d) 8192 MB  

---

**9.** In the Linux login prompt, why is your password invisible when you type it?

a) The terminal is broken  
b) It is a security feature to prevent shoulder-surfing  
c) Linux does not store passwords  
d) You must press Enter before characters appear  

---

**10.** Which command in AlmaLinux is equivalent to Ubuntu's `apt install`?

a) `pkg install`  
b) `pacman -S`  
c) `dnf install`  
d) `brew install`

## Answer Key

| Q | Answer | Explanation |
| :--- | :--- | :--- |
| 1 | **b** | Linus Torvalds released the first Linux kernel in 1991 |
| 2 | **b** | "GNU's Not Unix" — a recursive acronym |
| 3 | **c** | FreeBSD is a separate Unix-like OS, not a Linux distribution |
| 4 | **c** | Ubuntu uses `apt` (Advanced Package Tool) |
| 5 | **b** | `wsl --install` installs WSL 2 with Ubuntu by default |
| 6 | **d** | AlmaLinux is a binary-compatible rebuild of RHEL |
| 7 | **c** | No licensing cost and excellent stability are Linux's main server advantages |
| 8 | **c** | 2048 MB (2 GB) is the minimum; 4096 MB is recommended |
| 9 | **b** | Invisible input prevents others from reading passwords over your shoulder |
| 10 | **c** | AlmaLinux/RHEL-family systems use `dnf install` |
