# Hands-On Labs

These labs turn the reading into skills. Do them **in order**, in a real Linux environment (see
[Setting Up a Practice Environment](../README.md#setting-up-a-practice-environment)).

> ⚠️ **Practice on a throwaway system** — a VM or WSL — never on a machine with data you care
> about. Some steps intentionally create and delete files and users.

| Lab | Topic | Skills |
| :--- | :--- | :--- |
| [Lab 01](lab-01-users-and-permissions.md) | Users, groups & permissions | `adduser`, `usermod`, `chmod`, `chown` |
| [Lab 02](lab-02-ssh-keys.md) | Passwordless SSH | `ssh-keygen`, `ssh-copy-id`, `sshd_config` |
| [Lab 03](lab-03-files-and-text.md) | Files, pipes & text | `find`, `grep`, `awk`, pipelines |
| [Lab 04](lab-04-services-and-firewall.md) | Services & firewall | `apt`, `systemctl`, `ufw` |

Each lab lists **objectives**, numbered **tasks**, and a **verify your work** checklist. Try every
task before peeking at the collapsible hints.
